# NC WorldBattle

回合制 3D 即时战略，浏览器里直接玩。2–4 名玩家各占地图一角，每回合掷骰子争夺行动点，采集矿石 / 石油 / 肉，建设基地、训练部队，在终局决出胜负。从第 5–8 回合起，五种外星人——克洛伊、奎德、牛美菱、神坦、鬼魅——会每隔几回合随机到来一个。

地图每局随机生成（中型 20×20 或大型 25×25）：一条带两座桥的水道横贯战场，另有湖泊、树林和山地，平原利于坦克、山地和树林利于步兵。每个回合开始镜头聚焦到你的领地，左上角的小地图随时可以回到全局。

消灭敌方单位、建筑和外星人都能得分：小地图下方的**积分榜**实时排名，打满回合后积分最高者获胜。军事基地可以升级，领地扩大一圈。

对局中随时按 **Esc** 暂停：液态玻璃风格的菜单里可以保存到 3 个存档位之一、重新开始或退出。首页的“加载存档”能从保存的那一刻原样接着玩。

规则、资源消耗规划和全部数值见 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)。

## 运行

```bash
npm install
npm run dev      # 打开 http://127.0.0.1:5173/
```

## 其它命令

```bash
npm test         # 规则、存档与菜单测试（骰子、经济、战斗、地形、五种外星人、积分、基地升级、存档读写与续局一致）
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览打包结果
```

## 结构

```
src/
  game/     规则核心，纯逻辑、不依赖渲染
    data.ts       所有数值（单位、建筑、资源、地形、地图大小、五种外星人、积分表）
    board.ts      棋盘几何、领地布局、地形通行、占位、寻路
    terrain.ts    随机地图生成（水道、桥、湖泊、树林、山地）
    engine.ts     回合流程与所有行动的裁决（含外星人行动、积分）
    ai.ts         电脑玩家
    __tests__/    规则测试
  render/   3D 画面（Three.js）：模型、场景、地形景物、特效、实体动画
  ui/       界面：首页、暂停菜单、存档、积分榜、侧边栏、小地图、图标、玩法说明、掷骰子、弹层、交互控制
docs/
  GAME_DESIGN.md  设计文档
```
