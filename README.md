# NC WorldBattle

回合制 3D 即时战略，浏览器里直接玩。2–4 名玩家各占正方形地图一角，每回合掷骰子争夺行动点，采集矿石 / 石油 / 肉，建设基地、训练部队，在终局按**积分**定胜负。地图每局随机生成，从第 5–8 回合起陆续有外星人来袭。

![tech](https://img.shields.io/badge/tech-Vite%20%2B%20TypeScript%20%2B%20Three.js-7dd3fc?style=flat-square)

## 游戏特色

- **随机战场**：中型 20×20 / 大型 25×25 地图，一条带两座桥的水道横贯战场，另有湖泊、树林和山地。平原利于坦克、山地和树林利于步兵；水里的桥路由规则决定，涉水、步兵与战斗机的通行方式各不相同。
- **回合制战棋手感**：掷骰子（并列加掷，点数高者先手），行动点只花在采集；每回合每个单位可移动一次、攻击一次。
- **五种外星人**：克洛伊（生命最高）、奎德（大型蜘蛛，孵小蜘蛛）、牛美菱（双马尾远程射手，4 格射程）、神坦（巨型坦克，3 格射程 + 近战，15 攻 / 8 防）、鬼魅（白色鬼魂，每回合瞬移）。每 5–8 回合随机出现，场上最多两个，不攻击其他外星人。
- **积分制胜负**：消灭单位、建筑、小蜘蛛都得分，外星人按伤害分配积分（最后一击额外 +100）；回合打满后积分最高者获胜。小地图下方的积分榜实时排名。
- **基地升级**：消耗三种资源各 1000，领地向战场方向多出一圈 13 格可建建筑（树林、山地、湖泊会被推平），生命上限 +10，外观换成更华丽的高级基地。
- **科技感首页**：NC WORLDBATTLE 大标题 + “新游戏 / 加载存档” 两个按钮，背后是缓慢自转的展示棋盘（五种外星人站在中央）。
- **暂停与存档**：对局中按 **Esc** 暂停（画面冻结），弹出 Apple 液态玻璃风格的菜单：继续游戏 / 保存存档（3 个存档位）/ 重新开始 / 退出到首页。首页“加载存档”可从保存的那一刻原样接着玩。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://127.0.0.1:5173/
```

从首页点“新游戏” → 设置玩家（人类 / 电脑）、回合数（最少 20）、地图大小 → “开始游戏”。

## 操作

| 操作 | 方式 |
|---|---|
| 镜头 | 左键拖动旋转 · 滚轮缩放 · 按住空格 + 左键拖动 / 右键拖动平移 |
| 查看地块 | 左键点击任意空地，底部卡片显示地形、加成、通行规则 |
| 选中单位 / 移动 / 攻击 | 左键点击单位 → 点蓝色格子移动 / 点红色目标攻击 |
| 取消选择 | 右键（对局中 Esc 是暂停菜单） |
| 暂停菜单 | **Esc** 或顶栏“菜单”按钮 |
| 小地图 | 左上角，点击回到全局视角 |
| 下一个待命单位 | Tab |
| 结束回合 | E 键或侧边栏底部按钮 |

完整操作表见 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) 第 10 节。

## 项目结构

```
src/
  game/     规则核心：纯逻辑、不依赖渲染
    data.ts       所有数值（单位、建筑、资源、地形、五种外星人、积分表）
    board.ts      棋盘几何、领地布局、地形通行、占位、寻路
    terrain.ts    随机地图生成（水道、桥、湖泊、树林、山地）
    engine.ts     回合流程与所有行动的裁决（含外星人行动、积分、基地升级）
    ai.ts         电脑玩家
    __tests__/    规则测试
  render/   3D 画面（Three.js）：模型、场景、地形景物、特效、实体动画
  ui/       界面：首页、暂停菜单、存档、积分榜、侧边栏、小地图、图标、玩法说明、弹层、交互控制
docs/
  GAME_DESIGN.md  设计文档（规则解读与数值表，权威来源）
```

架构边界：`game/` 只 import 自己的文件；`render/` import game/ 但不认识 ui/；`ui/` import game/ 和 render/。规则层无 DOM 依赖。

```bash
npm run build    # 类型检查（tsc strict）+ vite 打包到 dist/
npm run preview  # 预览打包结果
```
