# NC WorldBattle 游戏设计

> 回合制 3D 即时战略。2–4 名玩家各占正方形地图一角，每回合掷骰子争夺行动点，采集资源、建设基地、训练部队，打满所选回合数后基地生命值最高者获胜。地图每局随机生成：一条带桥的水道横贯战场，另有湖泊、树林和山地，站得不同打得就不同。

所有数值都以代码里的 `src/game/data.ts` 为准，本文与之同步。想调平衡，改那一个文件即可。

## 2. 一局怎么进行

```
回合开始
  └─ 所有存活玩家同时掷骰子 ──► 最大点数 +3 行动点，最小点数 +1 行动点，中间 0
  └─ （到了日子、且场上不足两个）一个外星人降临战场中央，种类随机
  └─ 外星人依次行动（各显神通），然后是奎德的小蜘蛛
  └─ 按点数从高到低，每人行动一个回合：
        采集（花行动点） → 建造 / 升级 / 生产（花资源） → 指挥部队移动、攻击 → 结束回合
下一回合 … 直到打满总回合数（最少 20）
```

- 2 名玩家：坐在**对角**。3 名玩家：西南、东北、东南。4 名玩家：四个角。
- 座位可设为人类或电脑。多人同一台电脑时可设多个“人类”轮流操作。

### 2.1 首页、暂停与存档

- **首页**：`NC WORLDBATTLE` 大标题，下面两个按钮——“**新游戏**”进入开局设置，“**加载存档**”列出 3 个存档位（地图缩略图、第几回合、轮到谁、什么时候存的）。背后是一块缓慢自转的展示棋盘：四个基地盖满建筑、外面列着部队、五种外星人站在中央，可以用鼠标拖动旋转。开局设置里按 Esc 或点“返回首页”回到首页。
- **暂停菜单**：对局中按 **Esc** 或点顶栏的“菜单”。画面冻结，弹出液态玻璃风格的菜单：继续游戏 / 玩法 / 保存存档 / 重新开始 / 退出到首页。再按一次 Esc 回到游戏；停在存档位列表或玩法页时按 Esc 先回到菜单。
- **玩法**：规则、操作和消耗一览放在暂停菜单的“玩法”里（顶栏“玩法说明”按钮也到这里），看的时候对局保持暂停。侧边栏不再有“玩法”页。
- **采集面板**：轮到人类玩家、且还有行动点时，右侧栏左边多出一块采集面板，列出三种资源的现有数量和这一次能采多少；点一种就花 1 行动点。行动点用完、或轮到别人时自动收起，镜头随之让回原位。
- **保存**：点一个存档位即可。覆盖别的对局会先确认；更新本局自己的存档位不用确认。列表会标出哪一个是“本局”的存档，以及是否有“新进度”（上次保存之后对局又有了变化）。退出时如果还有没保存的进度，提示里会说明。
- **读取**：只在首页读取。读档后从保存的那一刻原样继续：人类下到一半的回合、电脑玩家行动到一半、骰子刚掷完，都能接上（`src/game/__tests__/save.test.ts` 验证了读档后打完的结局与不中断时完全一致）。
- 存档只在本机的这个浏览器里（每份约 5–10 KB），清除浏览器数据会一并删除。版本对不上的旧存档会标成“无法读取”，可以覆盖或删除。

## 3. 掷骰子

- 每人掷一颗六面骰。两人、三人对局：点数最大者 **+3 行动点**，最小者 **+1 行动点**，中间的玩家 **0**。
- **四人对局**按名次来：第 1 名 **+3**、第 2 名 **+2**、第 3 名 **+1**、第 4 名 **0**。
- 最大点数并列：只让并列者加掷，决出谁拿 3 点。最小点数并列同理，决出谁拿 1 点。四人对局里第二、三名并列时也让这两家加掷。
- 全部同点：先加掷决出第一名，再在其余人中决出最后一名。
- 一回合的行动点合计固定：两三人 4，四人 6。

## 4. 地图

- 开局可选 **中型 20×20**、**大型 25×25** 或 **超大型 35×35**，四角各有一块 6×6 的基地区域（带颜色边框）。每局的地形都重新随机生成，同一个种子得到同一张图。
- **水道**：一条 1 格宽的河道纵贯或横贯整张地图，只走四个基地之间的中央地带，**恰好两座桥**，两桥之间至少隔 5 格水。士兵和运输车只能走桥，坦克可以直接涉水。
- **湖泊** 2–3 片、**树林** 若干片、**山地** 若干片，散布在开阔地上。
- 每个基地固定有：**军事基地**（2×2，开局就有）、**加工工厂**（开局就有）、卡车车库与两条运输通道。
- 基地外侧各有一处**矿山**（矿石）、**油田**（石油）、**牧场**（肉），资源点不会枯竭，会挡路。资源点贴着基地摆放（水道纵向时在基地的左/右一侧，横向时在基地的上方一侧），所以永远不会被水道和基地隔开；运输车沿固定的车道往返采集。
- 领地、车道、资源点周围、出兵点附近永远是平原，不会被随机成水、树林或山地。
- **地图上的建筑**（只有大型和超大型有）：单层房屋和高层大厦散布在四个基地之间的十字带上，各占 1 格，生命 10、防御 5。步兵、狙击手、反坦克战士可以走进去进驻（见第 7 节）；小地图上是一座小方块，没人占据时是灰色，被占据后变成那个玩家的颜色。

### 4.1 地形与加成

加成只作用于**站在该格上的单位**，单位走开就失效。攻击加成看攻击者脚下的格子，防御加成看目标脚下的格子；破甲无视防御值，所以也无视地形带来的防御。

| 地形 | 士兵（步兵、狙击手、反坦克战士） | 坦克类（各型坦克） | 通行 |
|---|---|---|---|
| 平原 | — | 攻击 **+2**，防御 **−2** | 所有单位 |
| 山地 | 攻击 **+2**，防御 **+1** | — | 所有单位 |
| 树林 | 防御 **+2** | 射程 **−2**（最低 1） | 所有单位 |
| 水道 / 湖泊 | — | — | 士兵、运输车不能进；坦克可涉水；战斗机飞越 |
| 桥 | — | — | 所有单位 |

举几个例子：坦克在平原上互相打是 (8+2) − (3−2) = 9；同一辆坦克躲在树林里打山地上的步兵只有 8 − 1 = 7；山地上的步兵打平原上的步兵是 3 + 2 = 5 点，而平原上的步兵打不进树林（3 − 2 = 1）。

## 5. 经济

### 5.1 采集

- 开局 1 台资源运输车。
- 每花 1 行动点：**全部**运输车出动，采集你选的一种资源，**每台 +100**。
  - 1 台车 + 3 行动点 = 300；4 台车 + 3 行动点 = 1200。
- 运输车由加工工厂生产，**每座加工工厂最多 4 台**（含开局那台）。要第 5 台就得再建一座工厂。

### 5.2 电力

- 每座**发电站供 3 座建筑**。
- 需要电力的建筑：加工工厂、军营、军工厂、军事机场、防御网、炮台、防空炮。军事基地和发电站本身不需要。
- 电力按**建造先后**分配，超出的建筑停机：不能生产、不能开火，防御网失效。
- 开局只有一座没电的加工工厂——第一件事通常是盖发电站。

### 5.3 产量上限

| 建筑 | 上限 |
|---|---|
| 加工工厂 | 每座容纳 4 台运输车 |
| 军营 | 每座每回合 4 名 |
| 军工厂 | 每座每回合 4 辆 |
| 军事机场 | 每座停靠 4 架战斗机 |

## 6. 资源消耗规划

### 6.1 思路

**收入基准。** 两人局每人每回合平均 2 点行动点，20 回合约 40 次采集指令。运输车从 1 台滚到 8 台，一局总资源约 **2 万–2.4 万**。四人局行动点更稀，约 **1.2 万–1.5 万**。

**价格锚点。** 4 台车采一次 = 400 资源。于是：

- 一辆坦克（350）≈ 一次采集；一辆天启（3650）≈ 九次采集；
- 一名步兵（200）≈ 半次采集，一名特种部队（1100）≈ 三次采集；
- 一套完整基建（电、网、兵营、车厂、第二工厂、约 5 座建筑加 8 台车）≈ 5000，大约第 6–8 回合成型；
- 剩下的钱大约够 **15–20 个单位**，正好是一屏能指挥过来的规模。

**三种资源各有不可替代的用途**，逼你做选择：

| 资源 | 用途 | 什么时候缺 |
|---|---|---|
| **矿石** | 所有建筑、所有单位的主料 | 永远缺 |
| **石油** | 所有载具、发电站以外的升级、机场 | 走装甲流时最缺 |
| **肉** | 三种步兵的口粮，以及**发电站的燃料** | 纯步兵流或大肆扩建时缺 |

发电站烧肉是刻意安排的：这样即使是纯装甲玩家也必须采肉，牧场不会变成摆设。

**贵的一定有说法，不是单纯数值膨胀：**

- **激光坦克**带“破甲”，无视防御值 —— 专克天启、神坦这类高防目标。
- **双管 / 天启**的多发武器每发单独扣防御，打薄皮目标强、打重甲反而吃亏。
- **导弹坦克**射程 5 > 炮台射程 4，是拔钉子工具。
- **防空坦克**对空攻击 ×2（对地 5、对空 10），射程 4；**天启双塔坦克**也能对空（每回合合计 8）。
- **战斗机**只有防空武器和天启打得到，对面没造防空就是白给。
- **导弹坦克 / 轰炸机**带“十字溅射”：打中的格子吃满，上下左右四格里的敌人各吃一半。往人堆里打。
- **克制**：狙击手对步兵类、反坦克战士对坦克类（含人形机甲）、特种部队对外星人双倍伤害。
- **轰炸机**只对地，射程 1，要飞到目标头上投弹；和战斗机一样只有防空武器和天启打得到。
- **地图上的房屋和大厦**是免费的掩体：狙击手进去后射程压到 3，但外面的敌人只能打建筑（防御 5）。

## 7. 战斗

**核心公式：伤害 = 攻击力 − 目标防御值（最低 0）。** 破甲武器不减防御。

这正是你给的示例：敌人攻击力 13、防御网防御值 2，基地 20 血承受 **11** 点伤害，剩 9 血。

| 规则 | 说明 |
|---|---|
| 防御网 | 基地内**每座建筑每次受击**都先抵扣它当前等级的防御值（2 / 3 / 4 / 6 / 8 点）。10 名步兵打有 4 级网的基地，每枪 0 伤害；破甲武器无视它 |
| 射程 | 按格数计。射程 1 必须贴脸（轰炸机就是这样），狙击手 6 格，导弹坦克 5 格；进了建筑的士兵最多 3 格 |
| 对空 | 战斗机只能被防空坦克、防空炮、天启双塔坦克击落。普通地面单位对它毫无办法。防空坦克对空攻击 ×2；天启对空每炮 4 |
| 多管 | 每一炮单独算伤害、单独扣防御：双管坦克两炮各 (5 + 地形) ，天启两炮各 (9 + 地形) |
| 十字溅射 | 导弹坦克、轰炸机：目标上下左右四格里的敌方地面单位、外星人、建筑各受 **一半攻击力 − 自身防御**。例：平原上的导弹坦克打坦克，目标 16 − 1 = 15，四邻各 8 − 1 = 7 |
| 克制 | 狙击手打步兵类、反坦克战士打坦克类（含人形机甲）、特种部队打外星人（含小蜘蛛）：攻击力翻倍后再扣防御。例：狙击手打步兵 5 × 2 − 1 = 9 |
| 建筑里的士兵 | 进驻后不能被单独攻击，敌人只能打建筑（防御 5、生命 10）。从里面开火：点自己的建筑，卡片上列出里面的士兵，高亮的那名负责开火，点别的士兵图标换人；目标红色高亮，点了就打 |
| 建筑被摧毁 | 里面每名士兵扣 3 点生命，不足即阵亡；幸存者站到建筑原来的格子和周围空格 |
| 解散 | 点自己占据的建筑，卡片上的“解散”：士兵出来站到周围的空格。周围空格不够时提示“附近有其他单位无法解散” |
| 射程圈 | 选中自己的单位或炮台、或点开敌方单位 / 外星人时，地面上画出它的攻击范围：一个圆，半径 = 射程 + 半格。自己的琥珀色，敌方和外星人红色。射程按格数计，四个斜角方向实际能多够到一点，红色目标高亮才是准确的 |
| 已行动 | 一个单位在同一回合里既走完又打完，就变成灰石雕的颜色（它自己的移动和开火演完之后）。点“结束回合”的瞬间恢复原色；它的行动权要等到该玩家下一回合才回来 |
| 移动 | 步兵系 3 格（特种部队、人形机甲 4 格）、坦克 4 格、战斗机 8 格、轰炸机 4 格。不能穿过建筑、资源点和其他单位，不能贴着障碍抄斜角；士兵走进可进驻的建筑就停在里面。飞机飞越一切 |
| 水与桥 | 士兵、运输车不能进水，要绕到桥上过河；坦克可以直接涉水。电脑玩家的步兵会自己找桥 |
| 地形 | 站着的格子会改攻、防、射程，见 4.1。选中单位时卡片上显示实际数值和地形带来的增减 |
| 反击 | 敌人攻击你基地里的建筑时，你每座**通电**的炮台（对地面）/ 防空炮（对空中）各还击一次，每个敌方回合一次 |
| 摧毁建筑 | 建筑可被打掉。发电站没了，靠它供电的建筑跟着停机 |
| 出局 | **军事基地生命归零即出局**，名下所有单位和建筑清空 |
| 积分 | 消灭敌方的单位、建筑都得分；打外星人按伤害分积分，补刀另有加分。见第 9 节 |

### 7.1 军衔

每个战斗单位（运输车不算）都有军衔，新造出来的都是**下士**。

| | 攻击力、生命 | 防御力 | 晋升到这一级的花费 |
|---|---|---|---|
| 下士 | 卡面的数值 | 卡面的数值 | — |
| 中士 | 卡面的 1.5 倍（四舍五入） | +4 | 该单位造价的 100% |
| 上士 | 卡面的 2 倍 | +10 | 该单位造价的 150% |

例：坦克 8 / 15 / 3 → 中士 12 / 23 / 7 → 上士 16 / 30 / 13；步兵 3 / 6 / 1 → 5 / 9 / 5 → 6 / 12 / 11；天启每炮 9 → 14 → 18（两炮合计 18 → 28 → 36），对空每炮 4 → 6 → 8。

- **晋升**：在自己的回合点自己的单位，卡片上按「升级」，窗口里再按一次「升级」。钱当场扣，单位的生命**补满**，头顶挂上臂章；它本回合的移动和攻击不受影响。
- 地形的加减照旧叠在上面（平原上的中士坦克：攻击 12 + 2，防御 7 − 2）。克制的双倍照旧先算。
- 排名时比的「攻击力」也按军衔算。

## 8. 外星人

**第 5–8 回合之间的某一回合来了第一个，之后每隔 5–8 回合再来一个**，种类随机、顺序不固定。场上同时**最多 2 个**：到了日子却已有两个，就不来，并重新排下一次的日期。两个同时在场上时不会是同一种。外星人**只攻击玩家，互不攻击**。

**后到的更强。** 下表是**第一个降临**的外星人的数值；第二个在表里的数值上 +20%，第三个 +40%，以此类推（按表里的数值算，不是一个个叠乘），只影响生命、攻击、防御。例如第三个降临的克洛伊：生命 189、攻击 18、防御 6，射程和移动照旧。

| 外星人 | 外观 | 生命 | 攻击 | 防御 | 射程 | 移动 | 本事 |
|---|---|---:|---:|---:|---:|---:|---|
| 克洛伊 | 紫色的大眼怪物 | **135** | 13 | 4 | 2 | 2 | 没有特殊能力，但生命值最高 |
| 奎德 | 大型蜘蛛 | 75 | 5 | 5 | 1 | 3 | 每回合孵出 **1–3 只小蜘蛛**（一窝至多 8 只） |
| 牛美菱 | 双马尾的小女孩 | 53 | 10 | 2 | **4** | 3 | 隔着 4 格开火：攻击高，生命低 |
| 神坦 | 巨型坦克 | 90 | **15** | **8** | **3** | **1** | 攻防都是最高的，远程近战都行，但走得很慢 |
| 鬼魅 | 白色的鬼魂 | 45 | 13 | 2 | 1 | **瞬移** | 每回合出现在不同的地方，攻击之后立刻消失 |

| 小蜘蛛 | 数值 |
|---|---|
| 生命 / 攻击 / 防御 / 移动 | 3 / **4** / 1 / 3 |
| 行为 | **随机**挑一个目标走过去，攻击够得着的任何东西；不挑软的 |
| 积分 | 踩死一只 10 分，外加一点资源 |

共同规则：

- **对空**：克洛伊、奎德（和小蜘蛛）、牛美菱只打地面和建筑，打不到飞机；神坦对空射程 2；鬼魅对空对地。
- 每回合掷完骰子后、任何玩家行动之前，外星人先行动，然后是小蜘蛛。
- 目标优先级：单位（血最少的先）→ 普通建筑 → 军事基地。射程大于 1 的够得着就原地开火；近战的先朝最近的玩家目标走（七成），再咬。
- 外星人涉水、不受地形影响；玩家单位不能走进外星人或小蜘蛛占着的格子。
- 被基地里的炮台 / 防空炮反击是会死的。
- 奖励（资源）和积分都**按各玩家造成的伤害比例**分配，所以伤害最多的拿得最多；补上最后一击的玩家另加 **100 分**。奎德倒下时，它的小蜘蛛一并消失。

克洛伊的攻击力 13 就是你第一条需求示例里的那个数字：打没有防御网的基地一下 13 血，打有防御网的基地 11 血。防御值 4 让步兵（攻 3）和狙击手（攻 5 只剩 1）几乎打不动它 —— 想拿奖励得上反坦克战士、坦克或激光武器（特种部队打它一下 16 − 4 = 12）。神坦防御 8，更是只有破甲武器和天启啃得动。以上都是第一个降临的数值；后到的每样多两成，小蜘蛛一口 4 − 1 = 3，两口咬死一个步兵。

### 8.1 隐藏外星人

三种 **BOSS**，从不当第一个降临；之后每次降临有 35% 是它们之一，场上同时最多一个。它们同样随降临次序变强（第三个降临的是原参数的 1.4 倍，第二形态也一样）。**玩法说明里只有第一形态的数值和一句隐晦的介绍**，下面是全貌：

| 外星人 | 外观 | 生命 | 攻击 | 防御 | 射程 | 移动 | 对空 | 本事 |
|---|---|---:|---:|---:|---:|---:|---|---|
| 拓龙 | 绿色的恐龙 | 45 | 12 | 10 | 2 | 4 | 否 | 倒下后原地变成飞龙 |
| ↳ 拓龙 | 黑色的飞龙（悬空） | 45（回满） | **18** | 6 | 3 | 6 | 是 | 火球带十字溅射（四邻各 9 − 防御） |
| 泽参 | 岩石巨人 | 100 | 10 | **18** | 2 | 2 | 否 | 倒下后碎成 2 只小岩石巨人 |
| ↳ 小岩石巨人 ×2 | 小块的岩石巨人 | 30 | 5 | 10 | 2 | 2 | 否 | 全部打完才有奖励 |
| 雅千 | 悬在空中的女神（白色能量护盾） | 75 | 15 | 12 | 3 | 4 | 是，且悬空（只有防空武器和人形机甲打得到） | 被打立刻反击（6 − 防御，不限射程）；每 2 回合对自身 3×3 释放能量（8 − 防御），被击杀的士兵变成骷髅兵 |
| ↳ 骷髅兵 | 白骨小兵 | 2 | 2 | 0 | 1 | 1 | 否 | 随机攻击，雅千倒下即消失 |

- 奖励在**最后一个形态 / 最后一只**倒下时才发，按大家对所有形态造成的总伤害分成：拓龙 积分 600、矿石 2000 / 石油 1400 / 肉 1400；泽参 550、1800 / 1200 / 1200；雅千 650、2200 / 1500 / 1500。
- 悬空的（飞龙、雅千）占着格子，地面单位走不进去，飞机也不能停在上面。
- 数值上要有数：泽参只有激光坦克的破甲伤得到；雅千只有毒刺防空炮和人形机甲伤得到（见第 1 节第 66 条）。

## 9. 胜负

- 开局可选**总回合数**，最少 20 回合。
- 打满后，**积分最高者获胜**——就算一座基地都没打穿，也能靠积分赢。积分相同则比**基地生命值**，再相同比**攻击力**，再相同按座位顺序。
- 积分怎么来（小地图下方的**积分榜**实时显示排名）：

| 事由 | 积分 |
|---|---|
| 消灭敌方单位 | 步兵 20 · 狙击手 / 反坦克战士 30 · 坦克 40 · 防空坦克 50 · 双管坦克 60 · 导弹坦克 / 战斗机 70 · 激光坦克 80 · 天启 120 |
| 消灭敌方建筑 | 发电站 30 · 加工工厂 / 军营 / 炮台 / 防空炮 40 · 军工厂 / 机场 60 |
| 打掉军事基地 | 300 |
| 小蜘蛛 | 10 |
| 外星人被击败 | 它的积分（克洛伊 400、神坦 450、奎德 300、牛美菱 / 鬼魅 250）按伤害比例分给所有出过力的人；补刀者 +100 |

- “攻击力”= 所有存活战斗单位的攻击力 + 通电的炮台、防空炮的攻击力之和，只在积分和生命值都相同时才用到。
- 中途基地全被打掉，只剩一人时立即结束，存活者获胜（“统一战场”）。出局的玩家排在所有存活者之后。

## 10. 操作

| 操作 | 方式 |
|---|---|
| 镜头 | **每个回合开始时自动聚焦到当前玩家的领地**。左上角的**小地图**显示整张地图（地形、四个基地、单位、外星人、白框是当前视野），**点击小地图回到全局视角**；顶栏“全局视角”按钮同理 |
| 转动视角 / 缩放 / 平移 | 左键拖动 / 滚轮 / **按住空格 + 左键拖动**或右键拖动 |
| 查看地块 | 左键点击任意空地：底部卡片显示坐标、地形、加成、通行规则、属于谁的领地、这里有什么 |
| 选中自己的单位 | 左键点击：头顶出现绿色倒三角，蓝色格子 = 可移动，红色格子 = 可攻击。底部卡片把生命、攻击、防御、射程画成格子再加数字：格子到参考卡上的数值为止是浅蓝色，地形加出来的部分接着往上数、是金色，地形扣掉的留成红色空格；数字写成 `9(+2)`、`1(−2)`。生命按比例分成 12 格，绿 → 黄 → 红 |
| 血条 | 只有受了伤的单位才在头顶显示血条：剩下多少是绿 / 黄 / 红，丢掉的是暗红，外面一圈浅色边框 |
| 移动 / 攻击 | 点蓝色格子 / 点红色目标。移动过的单位仍然保持选中（它还能攻击），范围圈也还在，但蓝色格子没有了——每个单位每回合只能移动一次。这时卡片下方写的是“本回合已经移动过，不能再移动；还能攻击一次：点击射程内的红色目标”。移动和攻击都用过的单位变成灰色，点击它只是查看（不再选中），卡片下方写的是“本回合已经移动并攻击过，不能再行动，下个回合恢复” |
| 从建筑进生产页 | 左键点击自己的加工工厂、军营、军工厂或机场，右侧栏跳到“生产”页，滚到该建筑那一组并高亮 |
| 取消选择 / 放弃放置 | 右键（对局中 Esc 是暂停菜单） |
| 暂停菜单 | **Esc** 或顶栏“菜单”按钮：继续游戏 / 玩法 / 保存存档 / 重新开始 / 退出到首页。暂停时画面冻结、电脑玩家停手 |
| 玩法说明 | 暂停菜单 →“玩法”（顶栏“玩法说明”按钮直接到这里），分节折叠，含建筑 / 单位消耗表 |
| 保存与读取 | 暂停菜单 →“保存存档”选一个存档位；首页 →“加载存档”接着玩 |
| 采集 | 右侧栏左边的**采集面板**，只在轮到你且还有行动点时出现：点一种资源就花 1 行动点，全部运输车出动。选建筑放置期间它会先收起 |
| 进驻建筑 | 选中步兵、狙击手或反坦克战士后，能进的房屋 / 大厦会亮蓝光；**点建筑本身**（或它的格子）即进驻。进去后楼顶插上你的旗帜（房屋插屋脊、大厦插屋顶），士兵不再占格子 |
| 从建筑里开火 / 解散 | 点自己占据的建筑：卡片列出里面的士兵，高亮的负责开火，点目标就打；“解散”让他们出来站到周围空格（见第 7 节） |
| 生产 | “生产”页只列出**已建成的建筑**能生产的单位：没建军营就看不到步兵，没建机场就看不到战斗机和轰炸机。每个单位一张**卡片**：图标和名字在上，消耗是一条胶囊（矿石、石油、肉都用图标 + 数字，已有的数量跟在后面），下面是 生命 / 攻击、防御 / 射程、移动 三行，每行是标签 + 格子 + 方括号里的数字（如 `[15]`）；“生产”按钮在右下角 |
| 攻击范围圈 | 选中自己的单位、炮台，或点开敌方单位 / 外星人：地面上一个圆圈标出它的射程（自己的琥珀色、敌方的红色），单位走动时圈跟着走；换到别的地形上，圈的大小跟着变 |
| 已行动的单位 | 同一回合里走完又打完的单位变成灰色（像石雕）。点“结束回合”立刻恢复原色 |
| 下一个还能行动的单位 | Tab 或“下一个待命”按钮 |
| 建造 | 在“建造”页点某座建筑的“放置”，领地里**能建的格子会绿色高亮**，鼠标移到哪里，哪里就立起一座**半透明的建筑**（能看到它建在那格的样子），脚下的占地格绿色可行、红色不行，点击即建；iPad 上没有悬停，先点一下格子看半透明的建筑，再点一次确认。放置期间采集面板收起，建好或取消后再出现。防御网覆盖全基地，点了直接建 |
| 升级基地 | “建筑”页里军事基地那一行的“升级”（三种资源各 1000）。领地向战场方向扩大一圈，新一圈可以建建筑 |
| 切换侧边栏页签 | 1 建造 · 2 生产 · 3 建筑 |
| 结束回合 | 侧边栏底部按钮或 E 键。还有行动点时会先确认 |
| 结算 | 战斗结束后可以“**再来一局**”（同样的设置开一局新地图）或“**返回首页**” |
| 触屏（iPad 版，或没有鼠标键盘的设备） | 左键 = 轻点；转动视角 = 单指拖动，缩放 = 双指捏合，平移 = 双指拖动；取消选择 = 轻点空地；暂停菜单 = 顶栏“菜单”；切换页签 = 点侧边栏顶部的页签。**放置建筑分两步**：先点一下格子看位置，再点一次确认（点别的格子换位置，“取消”放弃）。双指手势结束时不会被当成一次点击 |
